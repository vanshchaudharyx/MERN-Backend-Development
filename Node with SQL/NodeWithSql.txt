Using SQL from CLI-->
mysql -u root -p (run this command)

We can also make sql file to run it.
eg schema.sql
We can write command in this file and open our SQL cli and type source file .sql


schema.sql
    ↓
Write SQL commands
    ↓
Open MySQL CLI
    ↓
source schema.sql;
    ↓
MySQL executes all commands
    ↓
Database / Tables created

Now we will come on routing using REST concept.

Get        / => show no of users in db
Get        /user => show users(email,id,username)
Patch      /user/:id => username edit
Post       /user => new user
Delete     /user/:id => user delete
