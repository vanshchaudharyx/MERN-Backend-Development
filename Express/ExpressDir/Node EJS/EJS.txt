Templating==>
EJS(Embedded JavaScript templates)
EJS is a simple templating language that lets you generate HTML markup with plain javascript.\
This is very popular templating tools.

Interpolation Syntax =>
Interpolation refers to embedding expressions into marked-up text.

- It is used to make EJS templates dynamic.
- EJS allows us to embed JavaScript expressions inside HTML.
- Interpolation syntax is:

  <%= expression %> ==> Output the value into the template.

Example:
<h1>Hello <%= name %></h1>

Serving Static Files ==>

Static files are files like HTML, CSS, JavaScript, images, etc.
that are served directly to the client without dynamic processing.

To serve static files in Express:

app.use(express.static(folder_name));

Example:

app.use(express.static(path.join(__dirname, "public")));

Here, "public" is the folder containing our static files.

express.static() is built-in Express middleware.
