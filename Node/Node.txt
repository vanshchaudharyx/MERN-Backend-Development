Node.js =>
JavaScript Runtime Environment.

- It allows JavaScript to run outside the browser.
- It is mainly used for server-side programming.
- Initially, JavaScript mainly ran inside web browsers.
- Node.js was released in 2009.
- It is built on Google's V8 JavaScript engine.
- It is widely used to build backend applications, web servers and APIs.
- Node.js is based on JavaScript.

Node REPL =>
REPL stands for:
R → Read
E → Evaluate
P → Print
L → Loop

It provides an interactive environment to execute JavaScript code directly in the terminal.

Type `node` in the terminal  to enter the Node.js REPL.
We dont manipulate DOM elements from node.
Here GLOBAL object exists in which various types of functions are present.

Run JavaScript File using Node.js =>

1. Open the terminal in the directory where the `.js` file exists.
2. Run the command:

   node script.js

Example:
If `script.js` is inside `D:\Delta 9.0 (MERN)\node`

Then:
PS D:\Delta 9.0 (MERN)\node> node script.js

Node.js will execute the JavaScript file and show the output in the terminal.

Process object=>
-Process-This object provides information about,and control over,the current Node.js process.
-Process.argv-returns an array containing the command-line arguements passed when the node.js process was launched
